#タスたす

##アプリ概要
大学の課題管理アプリです。個人で課題を管理できるだけでなく、グループで課題を共有することができます。

##開発目的
大学の課題提出忘れという問題を解決するために開発しました。
一般的な課題管理アプリでは課題の登録自体を忘れる可能性があります。
そこで、グループ共有機能を実装し、メンバーの誰か一人が課題を登録すれば、グループ内で共有される仕組みにしました。
これにより、課題の登録忘れや提出忘れの防止を目指しました。

##使用技術
・Python
・Flask
・MySQL
・HTML
・CSS
・JavaScript

##主な機能
・ユーザー登録、ログイン
・グループ作成
・グループへの参加
・グループからの退会
・課題登録
・課題完了登録
・課題編集
・ログアウト

##工夫した点
グループで課題を登録した際に、全員が完了ボタンを押すことでリストから削除される仕組みを作りました。
各メンバーの完了状況が表示され、リストに残ります。
